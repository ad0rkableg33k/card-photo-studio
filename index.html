How To Use
1. Upload front (+ optional back)
2. Pick a card type preset
3. Draw foil region on character area
4. Tilt with mouse to preview
5. Switch to Embed Maker tab to generate listing code
How it works: Fill in your card image URL and settings below. The Embed Maker generates a self-contained HTML snippet you paste into any listing — Squarespace, Shopify, eBay, anywhere that accepts custom HTML. The widget is fully interactive (tilt, spin, foil) and needs no external dependencies.
Must be a publicly hosted image (Squarespace media, Imgur, GitHub raw, etc). No local files.
If provided, the widget will flip front-to-back on 360° spin.
X, Y = top-left corner · W, H = width/height of foil region. All values 0–1 (fraction of card size). Leave defaults for a standard character-area foil zone. Use the Studio tab's Draw Foil Region to find exact values — they'll sync here automatically!
Use 100% to fill the listing column, or a fixed px value.

How to add it to Squarespace
Upload your card image to Squarespace Media Library (or any public host like Imgur). Copy the direct image URL.
Paste the URL into the Card Front Image URL field on the left and set your preset.
Click Generate — preview the widget and tweak settings until it looks right.
Copy the embed code and go to your Squarespace product listing.
In the listing description, add a Code Block — paste the embed code in. Done!
The widget is 100% self-contained — no scripts to host, no CDN, no dependencies. It just works.
